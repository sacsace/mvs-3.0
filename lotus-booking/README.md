# Lotus Korean Hotel Booking Website

Static booking website starter for the Lotus Korean Hotel brand.

## Files
- `index.html` : main landing and booking form
- `styles.css` : visual styles
- `app.js` : basic form submission handler (client-side only)

## Deployment
Deploy this folder to the domain `hotellotus.in`.

Recommended next steps:
- Connect the booking form to MVS public booking APIs.
- Replace placeholder contact details.
- Add room images and pricing.
