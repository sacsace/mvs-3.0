# MVS Desktop Notifier

Windows 트레이 전용 경량 알리미입니다. (브라우저 미실행 시에도 동작)

## 특징
- 트레이 아이콘 + Windows 풍선 알림만 사용
- 시작 프로그램 기본 등록 없음 (OS 간섭 최소)
- PowerShell + WinForms (`NotifyIcon`) — 별도 런타임/Chromium 불필요

## 설치
1. `Install.bat` 실행
2. API Base URL 예: `https://your-host/api`
3. MVS 사용자 ID / 비밀번호로 로그인

## 웹 다운로드
MVS 「소식」→「알림 프로그램」페이지에서 ZIP을 받을 수 있습니다.
